dj-digger — test version / wersja testowa

Requires macOS 15 or newer. Choose arm64 for Apple Silicon (M-series),
x86_64 for Intel. Python, FFmpeg and the browser components are included.

Open the DMG and drag dj-digger.app onto Applications. Eject the disk image,
then open dj-digger from Applications. No terminal commands are needed.

This test app has no Developer ID signature or Apple notarization. macOS may
block its first launch. Only if you trust this download, use System Settings >
Privacy & Security > Open Anyway for this app. Do not disable system security.
This package is for testing; automatic updates are not included.
