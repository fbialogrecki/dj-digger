# DJ Digger architecture graph

Source snapshot from [`4bed67ac6cb465a743254edbf5e692883db8066c`](https://github.com/fbialogrecki/dj-digger/tree/4bed67ac6cb465a743254edbf5e692883db8066c).

The [interactive map](./) shows 173 source files and 476 links between them. The [full JSON](./graph.json) contains 4,302 nodes and 11,631 edges.

The graph was extracted from a clean Git archive of the public commit. The interactive map covers application code, the browser extension, the default-language website and shared components, packaging and deployment, selected current documentation, and the README screenshots. The JSON also covers test code, all Python scripts and additional technical documentation. The corpus excludes third-party test fixtures, historical plans, generated files, lockfiles, and translated route copies.

Graphify extracted code and Markdown structure. Selected workflow-to-code and screenshot relationships are marked as inferred with source evidence. QML has file and selected UI landmarks. External symbols without repository provenance are omitted. The linked code at the pinned commit is authoritative.

The viewer adapts the [Graphify 0.9.111](https://github.com/Graphify-Labs/graphify) HTML exporter under Apache-2.0. The adaptation adds a file-level map, pinned source links, responsive controls and a content security policy. The self-hosted vis-network 9.1.6 renderer is available under MIT or Apache-2.0.
