Setup

  1. Install the dj-digger desktop app (download) and start it. It registers its native host with this browser on its own.
  2. If "Site access" is missing, grant it above (or in the browser's extension settings).
  3. Leave the extension enabled. dj-digger opens its own window and never touches your other tabs.
